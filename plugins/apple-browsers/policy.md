# Apple browsers iOS provider policy

Use build-ios and verify-ios with MobileBuildMCP. Pass your owned simulator UUID as simulatorId on every targeted call, plus explicit build inputs and the canonical worktree derivedDataPath on build/product lookup schemas that support it. Never change shared session defaults or profiles, including sync_xcode_defaults. Keep Xcode auto-sync disabled. Report unsupported operations. The control panel may attach, detach, and take screenshots. Shell simctl is limited to pbcopy/pbpaste with explicit UUIDs, and bundled internal lifecycle create/shutdown/delete operations. Build and app interaction stay on MobileBuildMCP. This policy does not select a provider for macOS work.

Keep the main checkout on main. Use one worktree per PR or branch with sequential writers; read-only helpers need no worktree. Reuse the previous worktree on retry. Truly concurrent writers need separate worktrees. Follow [resource ownership](resources.md) for cache reclamation, simulator leases, and safe cleanup. The bundled lifecycle helper may create, shut down, or delete only within its ownership rules. No direct lifecycle shell fallback is allowed.
